# 平行空间算命 🔮

每一次梦境，都是你的意识与另一个平行时空的「你」产生共振的瞬间。这个项目是一个 AI 驱动的梦境解读工具——以「平行宇宙」为叙事框架，将你的梦解读为另一个宇宙中「另一个你」正在经历的人生片段。

## 这是什么

一个轻量娱乐向的创意工具。不是真的算命，不是心理学分析——而是一个用 AI 讲故事的方式来帮你理解梦境的实验。

**世界观设定**：梦 = 平行宇宙共振信号。你做过的每个梦，都是另一个时空中的你在向你发送碎片。

## 快速开始

### 方式一：浏览器直接使用
打开 `index.html`，填入你的 API Key（Anthropic 或 OpenAI），输入梦境，即可生成解读。

### 方式二：手动使用 Prompt
将 `system-prompt.md` 中的完整 System Prompt 复制到 ChatGPT / Claude 的自定义指令中，然后输入梦境描述。

## 输出结构

每次解读包含六个段落：
1. **梦境回响** — 重述你的梦，让你感到被理解
2. **符号捕捉** — 提取 2-3 个核心梦象并解读
3. **时空定位** — 描述这个梦连接的平行宇宙的世界基调
4. **另一个你的人生片段** — 核心叙事：那个时空的你在经历什么
5. **跨时空回响** — 对你此时此刻的启示
6. **共振指数** — 数据彩蛋 + 免责声明
